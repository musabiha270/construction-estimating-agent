AI Construction Cost Estimator — Nestimate

An AI-powered voice automation project designed for construction estimating. The system allows contractors to describe their construction projects through a voice call and receive a professional Bill of Quantities (BoQ)-style estimate report by email.

Project Overview

This project showcases a voice-based AI construction estimating workflow built for the Nestimate UK platform. It helps streamline the collection of project details, cost estimation, and delivery of estimate reports.

Key Features

* Voice-Based Project Intake: Collects construction project type and size through a voice call.
* Cost Breakdown: Searches an estimates database to retrieve relevant construction cost information.
* BoQ-Style Reports: Organizes estimated costs into a professional report.
* Automated Email Delivery: Sends estimate reports by email.
* Construction Cost Categories: Covers materials, labour, equipment, permits, profit margin, and project timeline, according to the configured workflow.

Workflow

1. A contractor calls the AI voice agent.
2. The agent collects the construction project’s details.
3. The automation searches the estimates database in Google Sheets.
4. The system prepares a construction estimate report.
5. The report is sent to the contractor by email.

Technology Stack

* Retell AI — Voice agent
* Make.com — Workflow automation
* Google Sheets — Estimates database
* Gmail API — Email delivery
